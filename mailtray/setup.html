Where to configure it

  1. Create or select a Google Cloud project

    Use a separate project named Mail Tray if you have another app. In every linked console page, confirm the project selector shows that project. Its consent-screen name appears at sign-in.

    Open Google project creation ↗
  2. Enable Gmail APIOpen Gmail API page ↗
  3. Add your Google account as a test user

    Under Audience, select External / Testing and add the exact address you'll sign in with. A Workspace admin may also need to permit API access.

    Open OAuth Audience ↗
  4. Create a Desktop app OAuth client

    Copy its client ID and secret. Choose Desktop app, not Web application. The app requests only Gmail read-only access.

    Open OAuth Clients ↗
